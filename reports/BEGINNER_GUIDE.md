# 2024 B题小白学习与下一步优化指南

## 一、先学什么

按下面顺序学习，不需要一开始就学遗传算法或机器学习。

1. **概率基础**：事件、条件概率、期望、方差、二项分布。
2. **统计检验**：原假设、备择假设、第一类/第二类错误、置信度、检验功效。
3. **期望成本**：理解“失败后重做”为什么会出现几何级数和 `1/(1-q)`。
4. **0-1决策**：把“检/不检、拆/不拆”写成0和1；变量少时直接穷举。
5. **贝叶斯基础**：Beta分布、二项抽样和后验分布，只学本题会用到的部分。
6. **Python基础**：函数、字典、列表、循环、模块导入、JSON，不必先学复杂类设计。
7. **结果验证**：极端参数测试、手算对拍、灵敏度分析、自动化测试。

## 二、怎样读懂当前项目

建议按以下顺序阅读：

1. `2024B题原题.md`：只看流程与参数，自己画装配树。
2. `code/params.py`：观察题面表格如何变成程序数据。
3. `code/problem1.py`：理解概率约束如何搜索样本量。
4. `code/utils.py`：重点理解零件成本、综合次品率和失败重做公式。
5. `code/problem2.py`：看四个0-1变量怎样产生16种组合。
6. `code/problem3.py`：看问题二的单层公式怎样复用于三个半成品。
7. `code/problem4.py`：最后再看Beta后验和不确定性传播。

第一次不要逐行抠语法。先对每个函数回答三个问题：输入是什么、输出是什么、它对应题目哪一步。

## 三、自己动手的最短路径

```powershell
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'
python -m pytest code/tests -q
python code/problem1.py
python code/problem2.py
python code/problem3.py
python code/problem4.py
```

然后完成三个小练习：

1. 把问题二情形1的调换损失从6改成30，只在内存副本中运行，观察成品检测决策是否变化。
2. 手算两个零件都检测时的综合次品率，检查是否等于题面成品装配次品率。
3. 把问题一的明确超标水平从12%改成15%，观察最小样本量为什么下降。

## 四、写建模题的固定模板

每一问都按同一顺序写：

1. 用一句话说明目标；
2. 列输入参数；
3. 定义决策变量；
4. 写必要假设，并说明不采用其他解释的原因；
5. 推导目标函数和约束；
6. 选择最简单可行的求解方法；
7. 回代验证结果；
8. 做灵敏度或不确定性分析；
9. 用表格和图说明结论。

## 五、下一步优化方案

### P0：先提高数学可信度

1. 对安全回流假设增加对照模型：最多返工1次、最多返工2次、吸收马尔可夫链。
2. 对问题一的8%/12%工程判别带做5档敏感性分析，并实现SPRT序贯检验，与固定样本方案比较平均样本量。
3. 为问题二选择1个情形，手工推导至少2种策略，与程序逐项对拍。

验收标准：不同回流口径的假设、公式、数值和适用场景能够对应，不把工程假设写成题目事实。

### P1：完善不确定性决策

1. 把问题四的统一样本量200改成“每类零件分别分配样本量”。
2. 将抽样成本计入目标函数，联合优化抽样量和生产决策。
3. 将后验样本数从240提高并做收敛检查；问题三候选集从80扩展到160、320作对照。
4. 同时报告期望利润最优与5%分位利润最优，形成风险偏好对比。

验收标准：扩大样本数和候选集后，最优决策及利润变化在预设容差内。

### P2：提升论文表达

1. 增加问题三装配树流程图。
2. 增加问题一判别带—样本量曲线和问题四样本量—利润/风险曲线。
3. 将所有假设放到独立表格，区分题面事实、统计设定和工程约束。
4. 再进入论文撰写与最终验收阶段。
